### Security review notes

- `NSAppTransportSecurity/NSAllowsArbitraryLoads = true` (P0-2).
- Setup password in plain-text UserDefaults (P0-3).
- `LinkingService.openRealApp` opens `https` URLs from the bundled catalog, user-triggered only — no remote command execution. Safe.
- `CloudSyncService` POSTs notes to a user-configured base URL; no credentials stored; fail-soft. Reasonable as documented.
- No secrets, keys, or credentials committed in the repository (grep for `sk-`, `AKIA`, `p8`, `.p12`, `provisioning` found nothing).

## 2. What works well (do not break)

- Boot → Setup → Lock → Desktop routing and persistence via `UserDefaults`.
- Window open / close / minimize / maximize / bring-to-front with z-order (`SystemState`).
- Floating windows route to the correct app view via `WindowView.content`.
- Real URL-scheme linking with https fallback; genuine `UIApplication.openURL`.
- WKWebView-based browser with back/forward/reload/home.
- Local notes with optional cloud sync and offline fallback.
- Calculator arithmetic, music player UI, calendar grid, weather, settings, wallpaper selection.
- Wallpaper assets bundled; graceful fallback if an asset is missing.
- Setup validation (name, age 1–120, password ≥ 4, confirmation match).
